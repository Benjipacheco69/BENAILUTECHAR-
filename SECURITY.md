# Política de seguridad

No publiques vulnerabilidades, contraseñas ni información sensible en Issues públicos. Comunica los problemas al responsable del repositorio o mediante el canal privado acordado con el docente.

No subir:
- Contraseñas, tokens, claves o archivos de configuración con secretos.
- Huellas, imágenes biométricas o plantillas reales.
- Datos personales reales innecesarios para las pruebas.

Esta política es inicial y debe acordarse con el equipo.
