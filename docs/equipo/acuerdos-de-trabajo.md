# Acuerdos de trabajo

1. Consultar Issues antes de iniciar tareas.
2. Crear ramas descriptivas.
3. Usar commits claros y pequeños.
4. Solicitar revisión de otro integrante en cambios importantes.
5. Mantener README y documentación actualizados.
6. No subir credenciales ni datos biométricos reales.
7. Comunicar bloqueos y cambios de planificación.
8. Diferenciar funciones implementadas de propuestas.

Estos acuerdos deben ser revisados y aprobados por el equipo.
