## Acuerdos tecnológicos actuales

- Dispositivo de marcación: teléfono Android compartido.
- Identificación: reconocimiento facial.
- Servidor: C#.
- Base de datos: SQL Server.

El reconocimiento facial todavía está planificado y no debe registrarse como implementado hasta que exista código y pruebas que lo demuestren.
