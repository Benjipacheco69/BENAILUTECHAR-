# Requisitos

La especificación detallada se encuentra en [Requisitos del sistema](requisitos/README.md).

Incluye RF-01 a RF-10: inicio, activación del lector, captura, validación de calidad, procesamiento, comparación, usuario no registrado, identificación confirmada, registro y resultado.

Incluye RNF-01 a RNF-05: objetivo de tiempo inferior a un minuto, seguridad y privacidad, usabilidad táctil, conectividad y guía ante capturas de baja calidad.

Son requisitos iniciales derivados de los materiales del proyecto. Deben validarse con el equipo y no marcarse como implementados sin comprobar el sistema.
