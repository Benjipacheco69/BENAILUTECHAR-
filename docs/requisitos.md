# Requisitos

La especificación detallada se encuentra en [Requisitos del sistema](requisitos/README.md).

La versión actual plantea requisitos para el registro de trabajadores, enrolamiento e identificación facial desde un teléfono Android compartido, registro de entradas y salidas, almacenamiento en SQL Server mediante un servidor C# y consulta de asistencias.

Estos requisitos describen el comportamiento esperado. Deben validarse con el equipo y no marcarse como implementados sin comprobar el sistema.
