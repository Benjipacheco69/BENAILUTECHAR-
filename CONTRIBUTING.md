# Guía de contribución

1. Revisar README, documentación e Issues antes de comenzar.
2. Crear ramas descriptivas: `feature/descripcion`, `fix/descripcion`, `docs/descripcion` o `test/descripcion`.
3. Usar commits claros: `feat:`, `fix:`, `docs:`, `test:` o `chore:`.
4. Enviar Pull Request explicando el cambio, Issue relacionado y pruebas realizadas.
5. Solicitar revisión de otro integrante.
6. Mantener documentación sincronizada con el código.
7. No subir credenciales, datos personales reales ni datos biométricos.
